# SleepFix
SleepFix website pengatur jadwal tidur yang membantu pengguna mengelola waktu istirahat agar lebih teratur. Dilengkapi jam real-time, animasi jam yang smooth, animasi awan, dan fitur perencanaan tidur. Dengan desain modern, responsif, serta mudah digunakan di HP dan komputer, SleepFix membantu membangun rutinitas tidur yang lebih baik setiap hari.
